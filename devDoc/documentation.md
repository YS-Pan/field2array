# 文档维护

项目目标维护于 `project-charter.md`，当前实现维护于 `system/`，独立任务的计划和进度维护于根 `tasks/`，完成任务及旧项目证据维护于 `archive/`。根 README 和 AGENTS 只提供入口。变更记录使用本地时区 Asia/Shanghai，按 `YYYYMMDD_HHMMSS_主题.md` 命名。

归档报告和聊天原件保持原文，现行解释写在索引与结论文档中，并指向原始文件或消息。区分用户决定、当时观察、已通过的验证与尚未确认的假设；历史请求按其日期和范围解释。

源码、配置、可维护的小型测试和总结文档进入 Git。选留原始日志和报告位于默认忽略的 `artifacts/`，其来源、哈希和覆盖范围在档案索引中说明；本次发布仅在 `.gitignore` 精确放行已审查的K4小结果和媒体，清单见[发布证据](archive/20261112-github-publication/published-evidence.json)。完整聊天日志、请求原文和记忆数据库不进入公开Git。备份项目时一并保留本机 `artifacts/` 与 `.basepack/`；凭据只保留在本机配置位置。共享环境和机器服务通过配置定位。

临时检查使用根 `tmp/`；任务结束前，将必须保留的结论和证据移入所属文档或归档位置。`tmp/` 可以整体清除。
