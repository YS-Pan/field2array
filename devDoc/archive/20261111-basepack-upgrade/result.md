## 新维护流程实测与余项

刷新宿主注册清单后，在获准的普通用户上下文运行默认全项目 maintain，完成2个机械批次、复用3块。Git默认发现及受管聊天合计128个来源、发现缺口为空；采集6个可证明归属本项目的聊天，保留24个来源。沙箱内的Codex SQLite运行时权限阻塞在该上下文解除。宿主另有336个归属未明条目，按原边界保留，不称作本项目缺少336个聊天。

固定回执列出115个语义候选来源。本轮优先发布并验收 README 和接入说明：2个来源、20个成员，无关系改动或失效；逐个回读20成员及18条保存依据、核全部行覆盖、实际search/neighbors均通过。这两份登记原件已同步至当前字节。

余下113个回执来源尚未接受，包含源码、测试和已采集聊天；部分近期聊天已有未发布草稿。业务结束已先 `memory stop`，再取消协调者和所有后代；后续任务按新入口继续维护，不将采集、向量覆盖或草稿称为语义完成。回执为 `.basepack/memory/maintenance/c935811d89f14fb084979cd0878b0e1c.json`，停止的 control 为 `.basepack/memory/upgrade-20261111-143353/task.control`。本记录和收尾变更记录生成于该回执截止后，留待下一次默认发现。

停止后的正式库验收为278/278活跃向量兼容、mandatory pending和知识pending均为0；README与接入说明已登记版本匹配当前文件，原39份来源快照仍保留、46条旧关系依据在正式库全部回读成功。全项目deep changes还包括截止后生成的本记录和变更记录，故最终115个变化候选与固定回执剩余113个不是同一统计范围。
